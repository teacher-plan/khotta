# محرّك الألعاب (نموذج أولي)

الفكرة مأخوذة من تحليل Wordwall بأداة REA: **المحتوى منفصل عن القالب**.
المعلّم يكتب المحتوى مرة واحدة، وكل قالب يقرأ الصيغة نفسها، فيتحوّل الاختبار إلى مطابقة بزرّ واحد.
لا نسخ لأي كود أو رسومات من Wordwall، والنموذج مكتوب من الصفر بهوية المنصّة.

## الملفات
- `engine.js`: المحرّك (التحقّق من المحتوى، الخلط، الأصوات، شاشة النهاية) وقالبا **الاختبار** و**المطابقة**.
- `games.css`: التنسيق، بألوان `activities/_kit.css` وخطوط النظام فقط، فيعمل بلا إنترنت.
- `play.html`: المشغّل. يقرأ `?src=ملف.json` من النطاق نفسه، وإلا المحتوى التجريبي المضمَّن. و`#quiz` أو `#match` يختار القالب.

## صيغة المحتوى
```json
{
  "version": 1,
  "title": "عنوان النشاط",
  "settings": { "shuffle": true, "perRound": 4 },
  "items": [
    { "q": "٣ + ٤ × ٢ =", "a": "١١", "wrong": ["١٤", "٩"] }
  ]
}
```
- الاختبار: `a` مع `wrong` خيارات مخلوطة، وعند الخطأ تظهر الإجابة الصحيحة.
- المطابقة: كل `q` يُطابَق بـ `a`، على جولات من `perRound` بطاقات (٣ إلى ٦). لذلك يجب ألّا تتكرّر الإجابة الصحيحة نفسها في سؤالين.

## إضافة قالب
```js
Games.register('wheel', { label: 'العجلة', build(api) { /* api.content, api.stage, api.finish(right, total) … */ } });
```

## الخطوات التالية المقترحة
1. جدول `games` في Supabase يخزّن المحتوى JSON (بضعة كيلوبايت لكل نشاط).
2. محرّر للمعلّم داخل `cycle1.html` يكتب الأسئلة ويختار القالب.
3. قوالب أخرى على الصيغة نفسها: العجلة، صواب أو خطأ، ترتيب، تصنيف.
