# هويّة إنستغرام — خُطّة

أصول جاهزة لحساب خُطّة على إنستغرام، مبنيّة على نفس ألوان وخط أيقونة التطبيق.

| الأخضر | `#5B8C5A` |

الخطوط: **Cairo** (عناوين) و **Tajawal** (نصوص فرعية) — نفس خطوط الموقع، عبر Google Fonts.

## أغلفة الهايلايت (`highlights/`)

ستّة أغلفة دائريّة 1080×1080، جاهزة للرفع مباشرة كأغلفة "قصص مميّزة":

1. `01-about.png` — عن التطبيق
2. `02-features.png` — المزايا
3. `03-pricing.png` — الاشتراك والأسعار
4. `04-faq.png` — الأسئلة الشائعة
5. `05-testimonials.png` — آراء المعلمين
6. `06-contact.png` — تواصل معنا

إنستغرام يقصّ الغلاف إلى دائرة تلقائيّاً، والتصميم محسوبٌ ليبقى داخل هذه الدائرة بأمان.

مجلد `highlights/glyphs/` يحتوي نفس الأيقونات لكن بخلفيّة شفّافة (بلا المربّع الملوّن) — لاستخدامها فوق أي بلاطة ملوّنة في قوالب المنشورات.

## قوالب المنشورات والستوري (`templates/`)

ملفات HTML قابلة للتعديل مباشرة (نص وألوان)، بأبعاد إنستغرام الحقيقية:

- `post-feature.html` — منشور مربّع (1080×1080) لعرض ميزة واحدة.
- `post-tip.html` — منشور مربّع (1080×1080) بصيغة "هل تعلمين؟".
- `story-cta.html` — ستوري (1080×1920) بخلفيّة خضراء ودعوة لإجراء.
- `story-quote.html` — ستوري (1080×1920) لعرض رأي معلّم/ة.

كل مكان قابل للتعديل معلَّم بتعليق `<!-- EDIT: ... -->` فوقه مباشرة في الملف — استبدلي النص بين `[ ]` بمحتواك الفعلي.

### طريقة التصدير إلى صورة

**الطريقة الأسهل (يدويّاً):**
1. افتحي الملف في متصفح Chrome.
2. عدّلي حجم نافذة المتصفح، أو استخدمي أدوات المطوّر (F12 → أيقونة الجوّال) واضبطي الأبعاد المخصّصة على 1080×1080 (للمنشورات) أو 1080×1920 (للستوري) بمقياس تكبير 100%.
3. لقطة شاشة كاملة للصفحة (Cmd/Ctrl+Shift+P → "Capture full size screenshot" في أدوات المطوّر).

**عبر سطر الأوامر (Chrome headless)** — بديلٌ سريع إن كان Chromium متوفّراً:

```bash
chrome --headless --disable-gpu --no-sandbox --hide-scrollbars \
  --force-device-scale-factor=1 --window-size=1080,1080 \
  --screenshot=post-feature.png "file://$(pwd)/templates/post-feature.html"
```

(للستوري استخدمي `--window-size=1080,1920`.)

### المنطقة الآمنة في الستوري

قوالب الستوري تترك نحو 250px فارغة أعلى وأسفل التصميم (طبقة `.safe-top`/`.safe-bottom`) لتفادي تغطية شعار الحساب وشريط الردّ في واجهة إنستغرام. أبقي أي نصّ مهمّ داخل هذه الحدود.
