# تشغيل «خطة» على كل منصّة

| المنصّة | النوع | الأسئلة | الكتب | الأدوات الآلية والفحوص |
|---|---|---|---|---|
| **Claude Code** | وكيل سطر أوامر | منبثقة (`/khotah`) | تُجلب آلياً | ✔ كلها |
| **Codex** (OpenAI) | وكيل سطر أوامر | نصّاً مرقّمة | تُجلب آلياً | ✔ كلها |
| **Gemini CLI** (Google) | وكيل سطر أوامر | نصّاً مرقّمة | تُجلب آلياً | ✔ كلها |
| **Claude.ai** | محادثة | نصّاً | ترفق صفحات الدرس | ✔ غالباً (تنفيذ الشيفرة)، بلا إنترنت |
| **ChatGPT** | محادثة | نصّاً | ترفق صفحات الدرس | جزئياً (محلّل البيانات)، بلا إنترنت |
| **Gemini** (التطبيق والموقع) | محادثة | نصّاً | ترفق صفحات الدرس | ✘ — العرض والملخّص HTML يكتبهما النموذج |

أفضل النتائج في وكلاء سطر الأوامر (جلب الكتب، ومطابقة الدروس، وقصّ صور الأسئلة، والفحوص الآلية)؛
والمحادثات تُنتج عرضاً وملخّصاً جيّدين من **الصفحات المرفقة**.

المتطلبات لوكلاء سطر الأوامر (مرّة واحدة):
```bash
pip install pymupdf pillow segno opencv-python-headless
npm i -g playwright && npx playwright install chromium     # للملخّص PDF والفحوص (اختياري)
```

## Claude Code
1. انسخ `.claude/skills/khotah` إلى `~/.claude/skills/khotah` (لكل مشاريعك) أو `<مجلد التحضير>/.claude/skills/khotah`.
2. افتح Claude Code في مجلد التحضير واكتب `/khotah`.

## Codex
1. انسخ المجلد `khotah` إلى `~/.codex/skills/khotah` بحيث يكون `~/.codex/skills/khotah/SKILL.md` مباشرةً
   (الإصدارات الأحدث تقرأ أيضاً `.agents/skills/khotah` داخل المجلد).
2. انسخ `AGENTS.md` إلى مجلد التحضير.
3. افتح Codex فيه واكتب: «استخدم مهارة khotah وحضّر الدرس الأول».

## Gemini CLI
1. ثبّت المهارة: `gemini skills install <مسار المجلد>/.claude/skills/khotah`،
   أو انسخ `khotah` إلى `~/.gemini/skills/khotah` (اسم المجلد يجب أن يبقى `khotah`).
2. انسخ `GEMINI.md` إلى مجلد التحضير.
3. افتح `gemini` فيه واكتب: «حضّر الدرس الأول بمهارة khotah». (تحقّق بـ `/skills list`.)

## Claude.ai (الموقع أو التطبيق)
**الطريقة الأولى — مهارة (الأفضل):**
1. فعّل «تنفيذ الشيفرة وإنشاء الملفات» من الإعدادات ← الميزات (Capabilities).
2. من الإعدادات ← الميزات ← المهارات (Skills) ارفع الملف `khotah.zip`.
3. في أي محادثة: «حضّر الدرس الأول بمهارة khotah»، وأرفق صفحات الدرس.

**الطريقة الثانية — مشروع (Project):**
1. أنشئ مشروعاً «خطة».
2. الصق `platforms/CHAT_INSTRUCTIONS.md` في تعليمات المشروع.
3. ارفع ملفات المعرفة الآتية (القائمة أدناه).

## ChatGPT
**GPT مخصّص (يُشارك مع الزملاء):**
1. «استكشاف GPTs» ← «إنشاء» ← «تهيئة».
2. الصق `platforms/CHAT_INSTRUCTIONS.md` في «التعليمات».
3. ارفع ملفات المعرفة (أدناه)، وفعّل «محلّل البيانات / Code Interpreter».

**مشروع (Project):** التعليمات نفسها في تعليمات المشروع، والملفات نفسها في ملفات المشروع.

لبناء العرض بمولّد المهارة نفسه: ارفع `khotah.zip` في المحادثة، واطلب: «فكّ الحزمة وابنِ بـ build_deck.py».
(إن نقصت مكتبة في بيئة ChatGPT، يكتب النموذج ملف HTML بنفسه وفق القواعد.)

## Gemini (التطبيق والموقع) — Gem
1. «Gems» ← «Gem جديد».
2. الصق `platforms/CHAT_INSTRUCTIONS.md` في التعليمات.
3. ارفع ملفات المعرفة (Gem يقبل حتى ١٠ ملفات، فاختر أسلوبك ومادّتك).
4. أرفق صفحات الدرس في كل محادثة.

## ملفات المعرفة للمحادثات (١٠ ملفات على الأكثر)
من `.claude/skills/khotah/`:
1. `SKILL.md`
2. `rules/GENERAL.md`
3. `subjects/math.md` (أو ملف مادّتك)
4. `methods/explicit.md` (وأضف أسلوبك المفضّل إن كان غيره)
5. `methods/auto.md`
6. `guides/TOOLS.md`
7. `indexes/math-7-1.json` و/أو `indexes/math-7-2.json` (فهرس صفّك إن وُجد)
8. `engine/examples/fsimp_slides.py` (مثال كامل لدرس)
9. `engine/examples/fsimp_summary.py` (مثال الملخّص)

## تنبيهات
- لا ترفع الكتب كاملةً إلى GPT أو Gem مشترك (حقوق النشر). أرفق صفحات الدرس في المحادثة نفسها.
- المحادثات لا تحفظ `progress.json`: قل «الدرس التالي بعد ٦-٢» إن بدأت محادثة جديدة.
