# «خطة» — مهارة لتحضير الدروس (`/khotah`) لـ Claude Code و Codex و Gemini CLI والمحادثات

تحضّر لكل درس من كتب وزارة التربية والتعليم في سلطنة عُمان:
- **عرضاً تفاعلياً** للدرس كاملاً: ملف HTML واحد يعمل بلا إنترنت، بأقسام وفهرس تنقّل وملاحظات للمعلّم وملحق حلول تمارين الكتابين.
- **ورقة ملخّص** للطالب (PDF، صفحتان) فيها رمز QR يحمل إجابات «تدرّب».

بلا مفاتيح ولا حسابات خارجية. تبدأ بالرياضيات، وتُضاف المواد بالتدريج.

## التثبيت
1. انسخ المجلد `.claude/skills/khotah` إلى أحد المكانين:
   - داخل مجلد مشروعك: `<مشروعك>/.claude/skills/khotah` (للمشروع وحده)، أو
   - `~/.claude/skills/khotah` (لكل مشاريعك).
2. المتطلبات (مرّة واحدة):
   ```bash
   pip install pymupdf pillow segno opencv-python-headless
   npm i -g playwright && npx playwright install chromium
   ```
   (`python3` و`node` لازمان. إن تعذّر Playwright تُسلَّم ورقة الملخّص HTML لتطبعها من المتصفّح PDF.)

## الاستعمال
افتح Claude Code في مجلدٍ خاص بك (مجلد التحضير) ثم:
| تكتب | يحدث |
|---|---|
| `/khotah` | أول مرة: أسئلة قصيرة (الاسم، المادّة، الصفوف، الفصل، أسلوب التدريس، المشرف، جهاز العرض) تُحفظ في `khotah.config.json` |
| `/khotah إعدادات` | تعديل الإعدادات |
| «الدرس الأول» أو اسم الدرس أو رمزه | تحضير ذلك الدرس |
| «التالي» | الدرس الذي بعد آخر درس حُضِّر (`progress.json`) |
| «حضّر هذا الدرس بالاستقصاء» | أسلوب مختلف لهذا الدرس فقط |

**الكتب:** يجلبها الوكيل من المصادر في `guides/SOURCES.md`، أو تضعها أنت في `books/<المادة>-<الصف>-<الفصل>/` (مثل `books/math-7-1/`). الكتب لا تُرفق داخل المهارة؛ المهارة تحمل الطريقة والفهارس فقط.

## المنصّات: Claude Code و Codex و Gemini CLI و Claude.ai و ChatGPT و Gemini
| المنصّة | كيف | الكتب |
|---|---|---|
| Claude Code | انسخ `khotah` إلى `~/.claude/skills/` ← `/khotah` | تُجلب آلياً |
| Codex | انسخ `khotah` إلى `~/.codex/skills/` و`AGENTS.md` إلى مجلدك ← «استخدم مهارة khotah» | تُجلب آلياً |
| Gemini CLI | `gemini skills install …/khotah` و`GEMINI.md` إلى مجلدك | تُجلب آلياً |
| Claude.ai | ارفع `khotah.zip` في الإعدادات ← المهارات، أو مشروع بالتعليمات | ترفق صفحات الدرس |
| ChatGPT | GPT مخصّص أو مشروع: الصق `platforms/CHAT_INSTRUCTIONS.md` وارفع ملفات المعرفة | ترفق صفحات الدرس |
| Gemini | Gem: التعليمات نفسها وملفات المعرفة | ترفق صفحات الدرس |

الخطوات بالتفصيل، وقائمة ملفات المعرفة للمحادثات: **`platforms/README.md`**.
في وكلاء سطر الأوامر تأتي الأسئلة نصّاً مرقّمة (إلا Claude Code فمنبثقة)؛ وفي المحادثات أرفق صفحات الدرس
(كتاب الطالب، والدليل، والنشاط، والإجابات) فهي تكفي لإنتاج العرض والملخّص كاملين.

## أدوات الكتب الآلية
في `engine/tools/` (شرحها في `guides/TOOLS.md`، وتحتاج `pip install pymupdf pillow`):
| الأداة | العمل |
|---|---|
| `fetch_books.py` | يجلب كتاب الطالب والنشاط من بوابة الوزارة، ودليل المعلم من أفدني، ويتحقّق منها |
| `import_files.py` | يستورد ملفاتك (PDF، صور صفحات، ZIP) ويتعرّف نوع كل كتاب ويقرأ نصّه المشوّه بعد تطبيعه |
| `match_lessons.py` | يطابق كل درس بصفحاته في كتاب الطالب والدليل والنشاط، وعدد حصصه، وصفحات الإجابات |
| `crop_figs.py` | يقصّ صور الأسئلة والجداول والأشكال آلياً، أو بإحداثيات من شبكة مئوية |

## محتوى المهارة
```
.claude/skills/khotah/
  SKILL.md        سير العمل
  rules/          القواعد العامّة لكل المواد
  methods/        أساليب التدريس (أنا ← نحن ← أنتم، الاستقصاء، 5E، المشكلة، التعاوني، تلقائي)
  subjects/       قواعد كل مادّة (math.md أولاً) وقالب لمادّة جديدة
  guides/         مصادر الكتب ودليل الفهرسة ودليل الأدوات (TOOLS.md)
  indexes/        فهارس صفحات الكتب المشتركة (رياضيات الصف السابع ف١ أولاً)
  engine/         مولّد العرض والملخّص ورموز QR والفحوص الآلية، ومثال كامل لدرس
  engine/tools/   أدوات الكتب: الجلب، الاستيراد، المطابقة، تقطيع الصور
  templates/      أمثلة khotah.config.json و progress.json
AGENTS.md         تعليمات Codex (تُنسخ إلى مجلد التحضير)
GEMINI.md         تعليمات Gemini CLI (تُنسخ إلى مجلد التحضير)
platforms/        خطوات كل منصّة، وتعليمات المحادثات الجاهزة للّصق
```
إضافة أسلوب تدريس = ملف واحد في `methods/`. إضافة مادّة = نسخ `subjects/_TEMPLATE.md`.
