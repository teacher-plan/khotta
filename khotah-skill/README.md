# «خطة» — مهارة Claude Code لتحضير الدروس (`/khotah`)

تحضّر لكل درس من كتب وزارة التربية والتعليم في سلطنة عُمان:
- **عرضاً تفاعلياً** للدرس كاملاً: ملف HTML واحد يعمل بلا إنترنت، بأقسام وفهرس تنقّل وملاحظات للمعلّم وملحق حلول تمارين الكتابين.
- **ورقة ملخّص** للطالب (PDF، صفحتان) فيها رمز QR يحمل إجابات «تدرّب».

بلا مفاتيح ولا حسابات خارجية. تبدأ بالرياضيات، وتُضاف المواد بالتدريج.

## التثبيت
1. انسخ المجلد `.claude/skills/khotah` إلى أحد المكانين:
   - داخل مجلد مشروعك: `<مشروعك>/.claude/skills/khotah` (للمشروع وحده)، أو
   - `~/.claude/skills/khotah` (لكل مشاريعك).
2. المتطلبات (مرّة واحدة):
   ```bash
   pip install segno opencv-python-headless
   npm i -g playwright && npx playwright install chromium
   ```
   (`python3` و`node` لازمان. إن تعذّر Playwright تُسلَّم ورقة الملخّص HTML لتطبعها من المتصفّح PDF.)

## الاستعمال
افتح Claude Code في مجلدٍ خاص بك (مجلد التحضير) ثم:
| تكتب | يحدث |
|---|---|
| `/khotah` | أول مرة: أسئلة قصيرة (الاسم، المادّة، الصفوف، الفصل، أسلوب التدريس، المشرف، جهاز العرض) تُحفظ في `khotah.config.json` |
| `/khotah إعدادات` | تعديل الإعدادات |
| «الدرس الأول» أو اسم الدرس أو رمزه | تحضير ذلك الدرس |
| «التالي» | الدرس الذي بعد آخر درس حُضِّر (`progress.json`) |
| «حضّر هذا الدرس بالاستقصاء» | أسلوب مختلف لهذا الدرس فقط |

**الكتب:** يجلبها الوكيل من المصادر في `guides/SOURCES.md`، أو تضعها أنت في `books/<المادة>-<الصف>-<الفصل>/` (مثل `books/math-7-1/`). الكتب لا تُرفق داخل المهارة؛ المهارة تحمل الطريقة والفهارس فقط.

## التشغيل مع Codex
المهارة بالصيغة نفسها التي يقرؤها Codex (ملف `SKILL.md` في أوّله الاسم والوصف)، فلا تحتاج تعديلاً:
1. انسخ المجلد `khotah` (الذي داخل `.claude/skills/`) إلى `~/.codex/skills/khotah` بحيث يكون الملف في `~/.codex/skills/khotah/SKILL.md` مباشرةً.
2. ثبّت المتطلبات نفسها المذكورة في «التثبيت»، وحدّث Codex إلى آخر إصدار (المهارات في الإصدارات القديمة تجريبية).
3. افتح Codex في مجلد التحضير، واطلبها بالكلام: «استخدم مهارة khotah وحضّر الدرس الأول» (الأمر `/khotah` خاص بـ Claude Code).
4. **الفروق:** لا توجد أسئلة منبثقة، فتأتيك أسئلة الإعداد نصّاً مرقّمة في رسالة واحدة، وتجيب بالأرقام. وبقية العمل (الكتب، العرض، الملخّص، الفحوص) كما هي.

## التشغيل في محادثة (ChatGPT أو Claude.ai)
إن رفعت المهارة إلى محادثة لا تتصفّح الإنترنت ولا تملك مجلداً للكتب:
- تأتي أسئلة الإعداد **نصّاً** بدل النوافذ المنبثقة.
- **أرفق صفحات الدرس بنفسك** (صوراً أو PDF): صفحات الدرس في كتاب الطالب، وصفحاته في دليل المعلم، وكتاب النشاط إن وُجد، وصفحات الإجابات في الدليل. هذا يكفي لإنتاج العرض والملخّص كاملين.
- إن لم تتوفّر في المحادثة أداة تشغيل الأوامر فقد لا تُشغَّل الفحوص الآلية، وقد يُسلَّم الملخّص HTML لتطبعه PDF من المتصفّح.

## محتوى المهارة
```
.claude/skills/khotah/
  SKILL.md        سير العمل
  rules/          القواعد العامّة لكل المواد
  methods/        أساليب التدريس (أنا ← نحن ← أنتم، الاستقصاء، 5E، المشكلة، التعاوني، تلقائي)
  subjects/       قواعد كل مادّة (math.md أولاً) وقالب لمادّة جديدة
  guides/         مصادر الكتب ودليل الفهرسة
  indexes/        فهارس صفحات الكتب المشتركة (رياضيات الصف السابع ف١ أولاً)
  engine/         مولّد العرض والملخّص ورموز QR والفحوص الآلية، ومثال كامل لدرس
  templates/      أمثلة khotah.config.json و progress.json
```
إضافة أسلوب تدريس = ملف واحد في `methods/`. إضافة مادّة = نسخ `subjects/_TEMPLATE.md`.
