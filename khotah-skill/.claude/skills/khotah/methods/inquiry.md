# الاستقصاء: أنتم ← نحن ← أنا

يبدأ كل قسم بسؤالٍ أو موقفٍ يستكشفه الطلاب قبل أي شرح، ثم يُصاغ المفهوم معاً، ثم يُحكِمه المعلّم.

## المراحل
| المرحلة | ما يحدث | أنواع الشرائح |
|---|---|---|
| **🔎 أنتم: استكشفوا** | سؤال مفتوح، نمط، تجربة، أو بيانات من الكتاب يتأمّلها الطلاب في أزواج | «ماذا تلاحظ؟ ماذا تتساءل؟»، جدول يُكمَل، صورة سؤال الكتاب، مؤقّت |
| **🤝 نحن: نصوغ** | جمع ملاحظات الطلاب وصياغة القاعدة بكلماتهم ثم بلغة الكتاب | بطاقات تُكشف تدريجياً، مقارنة إجابات، قاعدة تظهر بعد النقاش |
| **👨‍🏫 أنا: أُحكِم** | المعلّم يثبّت القاعدة بمثال محلول ويعالج الخطأ الشائع | مثال محلول بخطوات، «انتبه ⚠️»، `quiz()` تحقّق |

## البنية في العرض الكامل
`cover` ← `goals` ← المفردات (تُكشف بعد الاستكشاف إن ناسب) ← لكل فكرة: `section` ← `remember` ← أنتم ← نحن ← أنا ← `exit_card` ← قسم الأخطاء الشائعة ← الواجب ← الخلاصة ← الملاحق.
- سؤال الاستكشاف من الكتاب (نشاط الدليل، «فكّر»، تمرين استقصائي) أولاً. إن أُضيف من خارج الكتاب يُذكر في القائمة.
- لا تُكشف القاعدة على شريحة الاستكشاف؛ ضعها في ملاحظة المعلّم مع الأسئلة الموجّهة المتوقّعة.

## شكل الملخّص
سؤال الاستكشاف وما لاحظناه (سطران) ← القاعدة ← مثال محلول ← انتبه ← تدرّب + QR.
