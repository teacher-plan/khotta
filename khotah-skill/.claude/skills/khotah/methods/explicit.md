# التدريس الصريح: أنا ← نحن ← أنتم (الأسلوب الافتراضي)

كل مهارة في الدرس تمرّ بالمراحل الثلاث، ولكلٍّ شارةٌ `mode()` ولونٌ ثابت وشريطٌ على طرف الشريحة.

## المراحل
| المرحلة | الشارة | ما يحدث | أنواع الشرائح |
|---|---|---|---|
| **👨‍🏫 أنا** (أزرق) | `mode('i')` | المعلّم يحلّ مثالاً ويشرح بصوتٍ عالٍ، والخطوات تظهر واحدةً بضغطة | نموذج بصري يُبنى، مثال محلول `STEPS/STP` (خطوة واحدة لكل سطر مع سببها)، قاعدة |
| **🤝 نحن** (أخضر) | `mode('we')` | سؤالٌ موجّه للصف («كم مرّة نكتب العدد ١٠؟») ثم نكشف الحل معاً | بطاقات تُقلب `FLIPS`، سؤال موجّه ثم كشف، نشاط الدليل |
| **✍️ أنتم** (برتقالي) | `mode('u')` | سؤال اختيارٍ تفاعليّ، ومؤقّت اختياري | `quiz()` بخيار خاطئ يكشف الخطأ الشائع، `timer(2)` |

## البنية في العرض الكامل (بلا حصص ولا دقائق)
1. `cover` ← `goals` ← المفردات.
2. **قسم لكل فكرة رئيسية في الدرس** (بترتيب الكتاب): `section` ← `remember` ← تهيئة قصيرة (أول قسم فقط، أو عند فكرة جديدة) ← أنا ← نحن ← أنتم ← `exit_card`.
3. **قسم «أخطاء شائعة»** (من الدليل): `section` ← `remember` ← شريحة «انتبه ⚠️» لكل خطأ ← `exit_card`.
4. الواجب (من الدليل) ← الخلاصة ← الملاحق.

**التهيئة:** نوّعها ولا تبدأ كل الأقسام بالشكل نفسه: موقف من بيئة الطالب العُمانية (السوق، البيت، المزرعة، الملعب، الفلج، الحافلة المدرسية…) يُطرح سؤالاً مفتوحاً، أو لغز قصير، أو تقدير سريع «كم تتوقّع…؟»، أو صورة يُسأل عنها «ماذا تلاحظ؟ ماذا تتساءل؟»، أو «أيّهما أكبر؟». ثم يُعاد إلى الموقف نفسه آخر القسم ليُحلّ. الموقف الحياتي المضاف من خارج الكتاب يُذكر في `tn()` وفي قائمة التسليم.
**«فكّر 💡»** لأسئلة التفكير الموجودة في الكتاب. والخلاصة في النهاية.

## شكل الملخّص
القاعدة ← مثال محلول بخطوات لكل فكرة (بترتيب أقسام العرض) ← انتبه (الأخطاء الشائعة) ← تدرّب + QR.
