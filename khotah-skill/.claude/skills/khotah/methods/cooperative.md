# التعلّم التعاوني (ومنه «الخبراء» Jigsaw)

## المراحل
| المرحلة | ما يحدث | أنواع الشرائح |
|---|---|---|
| **👥 التنظيم** | تكوين المجموعات والأدوار (قائد، كاتب، متحدّث، موقّت) | شريحة أدوار، مؤقّت |
| **🧑‍🔬 مجموعات الخبراء** | كل مجموعة تتقن جزءاً من الدرس (فكرة/مثال/تمرين من الكتاب) | بطاقة مهمة لكل مجموعة: الفكرة + مثال محلول + سؤال تحقّق |
| **🔄 المجموعات الأم** | كل خبير يعلّم زملاءه جزأه | ورقة تسجيل مختصرة، أسئلة موجّهة |
| **🤝 نحن** | المعلّم يجمع الأجزاء ويصحّح الأخطاء الشائعة | القاعدة الكاملة، «انتبه ⚠️» |
| **✍️ تحقّق فردي** | كل طالب يجيب وحده | `quiz()`، `exit_card` |

## البنية في العرض الكامل
`cover` ← `goals` ← المفردات ← `section('التنظيم')` ← قسم لكل جزء خبير (بطاقة المهمة ثم شريحة حلّه المخفية للمعلّم) ← `section('نجمع الأجزاء')` مع `remember` ← قسم الأخطاء الشائعة ← `exit_card` ← الواجب ← الخلاصة ← الملاحق.
- بديل أبسط: «فكّر ← زاوج ← شارك» لكل سؤال `quiz()`.
- لكل قسم رئيسي `remember` و`exit_card` كالمعتاد.

## شكل الملخّص
قسم لكل جزء خبير (قاعدة + مثال محلول) ← كيف تترابط الأجزاء ← انتبه ← تدرّب + QR.
