# تعليمات Gemini CLI

هذا مجلد تحضير دروس بمهارة «خطة» (`khotah`).
- ثبّت المهارة مرّة واحدة: `gemini skills install <مسار>/.claude/skills/khotah`، أو انسخ المجلد `khotah` إلى
  `~/.gemini/skills/khotah/` (لكل المشاريع) أو `.gemini/skills/khotah/` داخل مجلد التحضير. اسم المجلد يجب أن يكون `khotah`.
- انسخ هذا الملف إلى مجلد التحضير ليُقرأ في كل جلسة.
- عند طلب تحضير درس («الدرس الأول»، «التالي»، اسم درس أو رمزه) فعّل مهارة khotah واقرأ `SKILL.md` واتبعه حرفياً.
  إن لم تُفعَّل فاقرأ `.claude/skills/khotah/SKILL.md` بجانب هذا الملف.
- اطرح أسئلة الإعداد **نصّاً** مرقّمة باختيارات مرقّمة في رسالة واحدة، ثم انتظر الردّ.
- الأدوات الآلية للكتب في `<المهارة>/engine/tools/` وشرحها في `guides/TOOLS.md`. تحتاج `pip install pymupdf pillow`.
- خاطب المعلّم بالعربية، ولا تضع الكتب أو صورها داخل مجلد المهارة.
