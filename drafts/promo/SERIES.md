# سلسلة «مزايا خُطّة» — أربعة مقاطع (٢٠ ث لكلٍّ منها، عمودي وأفقي)

الهوية: «ملصق حركي» (VIDEO.md ٦-ب)، والإيقاع ١٢٠ BPM (٤٠ نبضة). بلا تعليق صوتي، وظهور الشعار مع انفجار الموسيقى عند الثانية ٣.
الموسيقى من النسخ المولّدة سابقاً، فلا تكلفة جديدة: ١ ← a (من ١٣ ث) · ٢ ← d (من ١٣ ث) · ٣ ← c (من ١٢ ث) · ٤ ← موسيقى الجولة a (من ١٥ ث).

البناء: سؤال (٠–٢٫٧٥) · الشعار + اسم الميزة (٣–٥) · عرض الميزة (٥–١٢) · العبارة (١٢–١٥) · الختام: الأيقونة + سطر الميزة + «ابدأ اليوم» + khotati.com (١٥–٢٠).
