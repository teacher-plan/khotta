# تشويق الورشة — «ما بعد الورشة»

## النسخة الفاتحة (٧٢ ث، عمودي وأفقي) — `workshop_teaser2_*.mp4`
خلفية كريمية فاتحة وبطاقات بيضاء بألوان هوية خُطّة. الموسيقى: موسيقى الجولة a (مشرقة)، والإيقاع مضبوط على الحركة.
| الوقت | المشهد |
|---|---|
| ٠–٦ | «ماذا ستأخذ من الورشة؟» ← «لنبدأ بالنتيجة.» |
| ٦–١٧٫٥ | العبارة الصريحة سطراً سطراً: «في نهاية الورشة، / كلّ ما عليك لتحضيرٍ متكامل لأيّ درس… / أن تذكر اسمَ الدرس فقط لـ Claude / ثم تحصل على هذه النتيجة ↓» |
| ١٧٫٥–٢٣ | محادثة Claude: يُكتب «الكسور العشرية» فقط ويُرسل، ثم «يُحضّر Claude الدرس…» وتُعلَّم المخرجات الست |
| ٢٣–٢٩ | النتيجة: صفحة الدرس بتصميم «الحصة الحيّة» + «صفحةٌ واحدة للدرس، فيها كلّ ما تحتاجه في الحصة» |
| ٢٩–٥٣ | «ما الذي تحصل عليه؟»: تُفتح كل بطاقة ٤ ث مع شرحها: التحضير (الأهداف/التهيئة/الأنشطة/التقويم) · العرض (نموذج العُشر = ٠٫١) · ملخّص الطالب PDF (القاعدة + مثال محلول، وتذييل «عمل/تحت إشراف») · الفيديو بالتعليق الصوتي · اللعبة (٣ من عشرة = ٠٫٣) · صفحات الكتاب |
| ٥٣–٦٥ | «ومعها أدوات الحصة الحيّة في خُطّة» (٢ ث لكلٍّ منها): المؤقّت · إشارة الهدوء · القرعة · النجوم · الشعبة · ملء الشاشة |
| ٦٥–٧٢ | «اسمُ الدرس فقط… والحصة كلّها جاهزة.» ← «نلتقي في الورشة» · «إعداد: أ. عيسى الحارثي» |
