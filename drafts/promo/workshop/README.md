# تشويق الورشة — «ما بعد الورشة» (٣٥ ث، عمودي وأفقي)
لمجموعة المتدرّبين قبل الورشة. الموسيقى: النسخة b (توتّر، ثم صمت ١٥–١٥٫٧٥، ثم انفجار عند ١٦ مع فتح الصفحة).
- ٠–٤: «بعد الورشة…» / «يكفي اسمُ الدرس.»
- ٤–١١: يُكتب «الدرس التالي: الكسور العشرية» في صندوق الطلب، ثم ضغطة إرسال، ثم «يُجهَّز كلّ شيء…»
- ١١–١٥: «ويصلك كلّ شيء:» ثم ست مخرجات تصل على الإيقاع: تحضير الدرس · العرض التفاعلي · ملخّص الطالب · فيديو الدرس · اللعبة التعليمية · صفحات الكتاب
- ١٦–٢٧: صفحة الدرس بتصميم «الحصة الحية» في خُطّة: الشريط الداكن (المؤقّت، الهدوء، القرعة، النجوم، ملء الشاشة)، والعنوان والتاريخ والهدف، ثم البطاقات الست. يُفتح العرض (نموذج العُشر: جزء من عشرة = ٠٫١)، ثم يُفتح الفيديو.
- ٢٧–٣٢: «اسمُ الدرس فقط… / والحصة كلّها جاهزة.»
- ٣٢–٣٥: «نلتقي في الورشة» · «إعداد: أ. عيسى الحارثي»
