# الأنشطة والفعاليات التفاعلية

قسمٌ مستقلّ داخل منصة «خطتي الفصلية»، يحتوي أنشطةً جاهزةً للعرض المباشر أمام
طلاب الحلقة الأولى (٧–١٠ سنوات) — بلا تحضير، وبلا أوراق، وبلا اتصالٍ بالإنترنت.

يُستعمل في: حصص الاحتياط · حصص النشاط · الفعاليات المدرسية · الفواصل التعليمية ·
حصص المهارات الحياتية · تغيير جوّ الحصة.

---

## ماذا تفعل المعلّمة؟

أربع خطوات، لا خامسة لها:

1. تفتح النشاط.
2. تختار المستوى وعدد الفرق.
3. تضغط **«ابدأ النشاط»**.
4. تُدير النشاط بالأزرار على الشاشة.

---

## حالة البناء

الأنشطة **الواحد والعشرون كلّها مكتملة ومختبَرة** — فحصٌ بنيويّ لكل ملف،
وتشغيلٌ فعليّ في المتصفح لكل نشاط (فتح، بدء، لوحة معلّمة، وضع عرض)،
واختبارٌ عميق للأنشطة ذات المنطق المركّب (العجلة، المدينة، الرحلة، الأكاديمية).

---

## البنية

```
activities/
├── index.html      ← فهرس الأنشطة (نقطة الدخول)
├── _kit.css        ← نظام التصميم المشترك
├── _kit.js         ← العُدّة المشتركة (مؤقّت، نقاط، لوحة معلّمة، أصوات…)
├── 01…21 (واحدٌ وعشرون نشاطاً)
├── دليل-الصور.md   ← أوصاف Nano Banana لكل نشاط
└── README.md
```

**لماذا ملفّان مشتركان بدل نسخ الكود في كل نشاط؟** لأن تصحيح خطأٍ واحد في
المؤقّت أو لوحة النقاط يجب أن يصل الأنشطة الواحد والعشرين دفعةً واحدة. القسم
كلّه يُنسخ كمجلّدٍ واحد، فلا يكسر هذا وعدَ العمل دون اتصال.

**لا شيء يُجلَب من الشبكة:** لا خطوط، ولا صور، ولا مكتبات. الخلفيّات مرسومةٌ
بـSVG داخل الملف، والأصوات مُركّبةٌ بـWebAudio لا ملفاتٍ مسجّلة.

---

## ما في كل نشاط

- **شاشة بداية:** الاسم، الوصف، العمر، الزمن، عدد الفرق، القيمة المستهدفة.
- **لوحة المعلّمة:** الهدف · الأدوات · التقسيم · الخطوات · الوقت · نصٌّ يُقرأ
  للطلاب · إدارة الصف · احتساب النقاط · مستويات الصعوبة · الأسئلة الختامية.
- **وضع العرض:** يُخفي كل إعدادات المعلّمة، ويُكبّر النص والأزرار، ويدخل ملء
  الشاشة، ويمنع الجهاز من النوم.
- **أدوات ثابتة:** إعادة · صوت · ملء شاشة · تعليمات — في الموضع نفسه دائماً.
- **نقاطٌ تُكافئ القيم:** أزرار جاهزة للتعاون والإصغاء والتعليل، لا للسرعة وحدها.
- **تأمّل ختامي:** لا ينتهي نشاطٌ بلا سؤال «ماذا تعلّمنا؟».

## التشغيل والاختبار

افتحي `index.html` مباشرةً في المتصفّح — لا خادم، ولا بناء، ولا تثبيت.

فحصٌ بنيويّ لكل الملفات:

```bash
node tools/check-html.mjs activities/*.html
```

## الإضافة إلى المنصة

انسخي مجلّد `activities/` كما هو إلى جذر الموقع، ثم أضيفي في قسم
«الاحتياط» رابطاً إلى `activities/index.html`. لا تعديل في `cycle1.html`
مطلوبٌ سوى الرابط.

---

## إضافة نشاطٍ جديد

انسخي أقرب نشاطٍ يشبه فكرتك، ثم غيّري ثلاثة أشياء:

1. **بيانات المحتوى** (المصفوفة أعلى السكربت) — الأسئلة أو المواقف أو الكلمات.
2. **`Kit.build({...})`** — العنوان، اللونان، مشهد SVG، ولوحة المعلّمة.
3. **دالّتا `home()` و`play()`** — شاشة البداية ومنطق الجولة.

كل ما عدا ذلك — المؤقّت، النقاط، الأصوات، وضع العرض، التأمّل — يأتي من
`_kit.js` جاهزاً. ثم أضيفي سطراً في مصفوفة `ACTS` داخل `index.html` مع
`ready:true`.

### واجهة العُدّة باختصار

```js
const K = Kit.build({ title, accent, accent2, scene, onRestart, teacher });
K.stage                      // مسرح النشاط
K.Timer({secs, ring, onEnd}) // مؤقّت: start/pause/reset/add
K.Teams(host, n)             // فرق: mount/award/ask/reset
K.valuesRow(teams, pairs)    // أزرار نقاط القيم
K.reflect(data, onAgain)     // شاشة التأمّل الختامي
K.SFX.ok() / .win() / .star()
K.say(msg, kind) / K.praise() / K.encourage()
K.Bag(items)                 // موزّعٌ لا يُكرّر حتى تنتهي المجموعة
```

## عن الصور

الخلفيّات والمشاهد مرسومةٌ بـSVG بخطّ اليد داخل كل ملف، لا مولّدةً بالذكاء
الاصطناعي. السبب عمليّ: الصورة المولّدة ملفٌّ ثقيل يحتاج تحميلاً، والوعد هنا
هو العمل في مدرسةٍ بلا شبكة.

إن أردتِ لاحقاً استبدال المشهد بصورةٍ مولّدة بـNano Banana، فأوصاف الصور
لكل نشاط موجودةٌ في `دليل-الصور.md`، وموضع الاستبدال سطرٌ واحد: ثابت
`SCENE` في أعلى سكربت النشاط.
