# «Exam-khotta» — مهارة إعداد الاختبارات القصيرة والأسئلة القصيرة (`/exam-khotta`)

لمعلّمي سلطنة عُمان: تُعدّ **الاختبار القصير** و**السؤال القصير** من كتاب الطالب ودليل المعلم، بمواصفات
**وثيقة تقويم تعلم الطلبة** المعتمدة للمادّة، وتُخرج لكل أداة:
- **النموذج (أ) والنموذج (ب)**: الشبكة نفسها بأسئلة مختلفة (PDF وWord).
- **دليل التصحيح**: شبكة المفردات وملخّص التوزيع مقابل المطلوب، وجدول التصحيح بأعمدة الوثيقة
  (رقم المفردة، عنصر التقويم، الهدف التعليمي، رقم الصفحة، الإجابة، الدرجة، الإرشادات) (PDF وWord).

قبل البناء يفحص الاختبار آلياً بمواصفات وثيقة مادّته: المجموع، والتوزيع (أهداف التقويم، الصعوبة، فروع المادّة)، وعدد المفردات
وأنواعها والممنوع منها، والبنية الثابتة، والبدائل ونسبة التخمين، وتطابق النموذجين؛ ثم **كتابة الرموز والتشكيل** و**نصّ كل آية**.

| المادّة | الوثيقة | ما تضبطه المهارة في الكتابة |
|---|---|---|
| الرياضيات ٥–١٠ | سبتمبر ٢٠٢٤ | الكسور، الأسّ أعلى يسار الأساس، الجذر بعلامة معكوسة كالكتاب، العشري الدوري، المتباينات |
| العلوم ٥–١٠، والأحياء والكيمياء والفيزياء ١١–١٢ | ٢٠٢٣ و٢٠٢٥ | أرقام لاتينية ووحدات SI داخل الجملة العربية، الصيغ والمعادلات الكيميائية، الترميز العلمي |
| اللغة العربية ٥–١٢ | ٢٠٢٥ | خط نسخ (Amiri) بتشكيل كامل، فحص آلي لأخطاء التشكيل، النصوص والأبيات، «ما تحته خط» |
| التربية الإسلامية ٥–١٢ | سبتمبر ٢٠٢٥ | الآيات تُجلب من quran.com بالمرجع (لا من الذاكرة) والاقتباس يُتحقّق منه، والأحاديث من الكتاب |

## التثبيت والمتطلبات
```bash
pip install pymupdf pillow python-docx
npm i -g playwright && npx playwright install chromium     # لملفات PDF (بدونها: HTML للطباعة + Word)
```
| المنصّة | التثبيت | الاستدعاء |
|---|---|---|
| Claude Code | انسخ `.claude/skills/exam-khotta` إلى `~/.claude/skills/` أو `<مجلدك>/.claude/skills/` | `/exam-khotta` |
| Codex | انسخ `exam-khotta` إلى `~/.codex/skills/` و`AGENTS.md` إلى مجلدك | «استخدم مهارة exam-khotta» |
| Gemini CLI | `gemini skills install …/exam-khotta` و`GEMINI.md` إلى مجلدك | «أعدّ اختباراً قصيراً بمهارة exam-khotta» |
| Claude.ai | ارفع `exam-khotta.zip` في الإعدادات ← الميزات ← المهارات | «أعدّ اختباراً قصيراً» + صفحات الدروس |
| ChatGPT / Gemini | GPT مخصّص أو Gem: الصق `platforms/CHAT_INSTRUCTIONS.md` وارفع ملفات المعرفة | + صفحات الدروس |
التفاصيل: `platforms/README.md`.

## الاستعمال
| تكتب | يحدث |
|---|---|
| `/exam-khotta` | أول مرة: الاسم، المدرسة، المديرية، العام، المادّة، الصفوف، الفصل، المراجِع ← `exam-khotta.config.json` |
| «اختبار قصير أول للصف السابع» | يعرض الدروس، فتختار ٤–٦ دروس، ثم يُعدّ النموذجين ودليل التصحيح |
| «سؤال قصير على ٣-٣ و٣-٤» | سؤال قصير (٥ درجات) من الدرسين |
| «عدّل المفردة ٣ في النموذجين» | تعديل ثم إعادة بناء |

الكتب يجلبها الوكيل (بوابة الوزارة وأفدني) أو تضعها في `books/<المادة>-<الصف>-<الفصل>/`؛ ولا تُرفق داخل المهارة أبداً.

## محتوى المهارة
```
.claude/skills/exam-khotta/
  SKILL.md        سير العمل
  specs/          مواصفات وثائق التقويم (.json للفحص الآلي، و.summary.md للقراءة) لخمس وثائق، وقالب لمادّة جديدة
  subjects/       قواعد الكتابة لكل مادّة: math، science، arabic، islamic
  guides/         قواعد كتابة المفردات، شكل ملف الاختبار والرموز، مصادر الوثائق والكتب، أدوات الكتب
  engine/         build_exam.py (الفحص والبناء)، notation.py (الرموز)، arabic_check.py (التشكيل)، notation_sheet.py (صفحة اختبار
                  الرموز)، spec_summary.py، docx_writer.py، tools/ (الجلب والاستيراد والمطابقة والقصّ، وquran.py لنصّ الآيات)
  engine/assets/  خطوط مضمّنة: Readex Pro، وAmiri وAmiri Quran (رخصة SIL OFL)
  indexes/        فهارس صفحات الدروس (رياضيات السابع ف١ وف٢)
  examples/       خمسة اختبارات كاملة: رياضيات ٧ (اختبار وسؤال قصيران)، كيمياء ١١، تربية إسلامية ٧، لغة عربية ٧
  templates/      مثال exam-khotta.config.json
AGENTS.md / GEMINI.md / platforms/   إعداد Codex و Gemini CLI والمحادثات
```
إضافة مادّة = ملفّا مواصفات في `specs/` وفق `specs/_TEMPLATE.md`.
