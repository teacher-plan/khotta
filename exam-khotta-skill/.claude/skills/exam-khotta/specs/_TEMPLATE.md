# إضافة مواصفات مادّة أو صفوف جديدة

1. **اجلب الوثيقة الرسمية** (`guides/SOURCES.md`) واقرأ أقسام الأسئلة القصيرة والاختبارات القصيرة **صوراً** (`import_files.py --render`)،
   فجداول المواصفات ونصّها المستخرج كثيراً ما يكون مشوّهاً.
2. **انسخ أقرب ملف** وعدّله (الأمثلة الخمسة تغطّي الأنماط كلها):
   | النمط في الوثيقة | انسخ |
   |---|---|
   | أهداف تقويم وصعوبة بنسب (٤٠/٤٠/٢٠) وشبكات مقترحة | `math-5-10.json` |
   | أهداف تقويم فقط، وأنواع مفردات تختلف بالصف | `science-5-10.json` |
   | أنواع ممنوعة، وأعمدة دليل تصحيح خاصة | `science-11-12.json` |
   | توزيع على فروع المادّة يختلف بين الاختبار الأول والثاني | `arabic-5-12.json` |
   | بنية ثابتة لكل سؤال (كتابة نص، حديث، موضوعي، مقالي) | `islamic-5-12.json` |
3. **مفاتيح الملف:**
   - `id`، `subject`، `grades`، `digits` (`ar` أو `latin` — انظر في كتاب الطالب)، `font` (`readex` أو `amiri`)، `docx_font`.
   - `document`: العنوان والطبعة والرابط وأرقام صفحات الأقسام (`pages_note`).
   - `fields`: حقول تصنيف المفردة كما تسمّيها الوثيقة: `{"ao": {"label": "هدف التقويم", "values": {"AO1": "المعرفة", …}}, …}`
     (`"optional": true` لحقل لا يُشترط).
   - `tools` ← لكل أداة (`quiz`، `short_test`): `name`، `page`، `duration_text`، `duration_short`، `max_guess`، `forbid_types`،
     `grid_fields` (ما يجب أن يتطابق بين النموذجين)، `answer_key` (أعمدة دليل التصحيح: `[["العنوان", "الحقل"], …]`، والحقول:
     `n` الرقم، `answer`، `marks`، `objective`، `page`، `guidance`، `unit`، أو أي حقل من `fields`)، `rules` (نصّ الوثيقة).
   - `bands` ← لكل نطاق صفوف (`"5-9"`، `"10"`…): `total`، `items`، `lessons`، `dist` (التوزيع بالدرجات: `{"ao": {"AO1": 4, …}}`)،
     `types_rule` (`mcq` و`long` و`other`: العدد والدرجات؛ `"long": null` يمنعها)، `calculator`، `grids`، و`slots` للبنية الثابتة
     (`[{"element": "quran", "qtype": "essay", "level": "recall", "marks": 3}, …]`).
   - `variants` (داخل النطاق) لاختلاف الأول والثاني: `{"1": {"dist": …}, "2": {"dist": …}}`، ويختار بـ `number` في ملف الاختبار.
   - ما لم تحدّده الوثيقة اتركه بلا مفتاح (لا يُفحص)، واذكر ذلك للمعلّم.
4. **ولّد الملخّص وتحقّق منه:** `python3 engine/spec_summary.py <المعرّف> --md specs`، وقارنه بالوثيقة سطراً سطراً.
5. **اختبر:** اكتب اختباراً تجريبياً، ثم `build_exam.py --check`، وجرّب مخالفة متعمّدة لكل قاعدة لترى أن الفحص يرفضها.
6. **اعرض على المعلّم** الملخّص ليقارنه بالوثيقة قبل الاعتماد، وأضف المادّة إلى جدول `SKILL.md` §٠.
