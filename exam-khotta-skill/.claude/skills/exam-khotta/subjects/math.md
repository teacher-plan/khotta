# الرياضيات — كتابة الرموز كما في كتب الوزارة (٥–١٠)

> مأخوذ من كتاب الطالب للصف السابع (الطبعة التجريبية ١٤٤٥هـ)، والقواعد نفسها في الصفوف ٥–١٠. التحقّق البصري: `engine/notation_sheet.py`.

| الشيء | كما في الكتاب | تكتب في ملف الاختبار |
|---|---|---|
| الأرقام | عربية (٠–٩) | أي أرقام؛ تُحوَّل آلياً (`digits: ar`) |
| الكسر العشري | «٣٫٤» | `٣.٤` (بلا مسافة) |
| القوائم | «١، ٢، ٣» | `١، ٢، ٣` (مع مسافة بعد الفاصلة) |
| السالب | «(−٥)» والإشارة يمين العدد | `(−٥)` بعلامة «−» U+2212 |
| الضرب والقسمة | «×» و«÷» | `×` و`÷` (لا x ولا *) |
| الكسر | خطّ أفقي | `{٣/٤}`، والعدد الكسري `{٢ ١/٣}` (الصحيح يمين الكسر) |
| كسر فيه عملية | | `{س + ١/٤}` البسط كله قبل «/» |
| الأسّ | **أعلى يسار** الأساس «²٥» | `٥^{٢}`، `س^{٢}`، `(−٣)^{٢}` |
| الجذر | علامة **معكوسة** (فتحتها يميناً وخطّها فوق العدد يساراً) | `√{٣٦}`، والتكعيبي `√[٣]{١٢٥}` (الدليل أعلى يمين العلامة) |
| العشري الدوري | خطّ فوق الرقم المتكرّر | `٠.‾{٣}` |
| المتباينات | «٣ < ٥» (تنعكس العلامة آلياً مع اتجاه السطر) | اكتبها بمعناها: `٣ < ٥` تعني «٣ أصغر من ٥» |
| المتغيّرات | حروف عربية (س، ص، ع، ل) | كما في الكتاب |
| ط | «ط» بمعنى π | `ط` |
| الزوايا | «ق∠أ ب ج = ٩٠°» | `ق∠أ ب ج = ٩٠°` |
| المستقيمات | «أب ∥ جد»، «م ن ⊥ ل ك» | `∥` و`⊥` |
| الوحدات | سم، م، كغم، ل، مل، سم^{٢} | `٢٥ سم^{٢}` |
| النسبة المئوية | «٢٥٪» | `٢٥%` (تُحوَّل إلى ٪) |

## أخطاء يمنعها الفحص الآلي (`notation.lint`)
- أسّ أو جذر بلا قوسين (`^٢`، `√١٦`)، وقوس غير مغلق.
- كسر بشرطة مائلة في النص (`٣/٤`) بدل `{٣/٤}` — تنبيه.
- الحرف x للضرب، والشرطة «-» علامةً للسالب — تنبيه.

## الأشكال
الأشكال الهندسية والبيانية ترسم بأبعاد مكتوبة بالأرقام العربية، والأحرف العربية للرؤوس (أ، ب، ج)، كما في الكتاب.
