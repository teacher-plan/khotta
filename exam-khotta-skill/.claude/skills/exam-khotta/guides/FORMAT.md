# ملف الاختبار (JSON)

ملف واحد يُبنى منه كل شيء: `python3 <S>/engine/build_exam.py <الملف>.json [--out مجلد] [--log <P>/exams/log.json] [--check]`.
أمثلة كاملة في `examples/`:
| المثال | المادّة | ما يوضّحه |
|---|---|---|
| `math7-1_short-test-1.json` | رياضيات ٧ | شبكة «مقترح ١»، إجابة طويلة بأجزاء |
| `math7-1_quiz-1.json` | رياضيات ٧ | سؤال قصير، أعداد عشرية |
| `chem11-1_short-test-1.json` | كيمياء ١١ | أرقام لاتينية، `ce{}`، معادلات وحسابات بخطوات |
| `islamic7-1_short-test-1.json` | تربية إسلامية ٧ | البنية الثابتة، `group` و`label`، `quran[…]` |
| `arabic7-1_short-test-1.json` | لغة عربية ٧ | نص قرائي وأبيات `passage`، الفروع، `u{}` |

## الرأس
```json
{
 "kind": "short_test",            // أو "quiz"
 "spec": "math-5-10",             // ملف المواصفات في specs/
 "subject": "math", "grade": 7, "semester": 1,
 "number": 1,                     // الأول أو الثاني (يغيّر المواصفات في العربية والتربية الإسلامية)
 "title": "الاختبار القصير الأول",
 "lessons": [{"code": "١-١", "title": "…", "pages": "١٦–٢١", "unit": "…"}, …],
 "calculator": null,              // اختياري: يُستنتج من الوثيقة حسب الصف
 "instructions": "أجب عن جميع الأسئلة في الورقة نفسها",   // اختياري
 "digits": null, "font": null,    // اختياري: تغلب المواصفات (ar/latin، readex/amiri)
 "header": {"school": "…"},       // اختياري: يغلب exam-khotta.config.json لهذا الاختبار
 "forms": {"أ": [مفردات…], "ب": [مفردات…]}
}
```

## المفردة
| الحقل | إلزامي | المعنى |
|---|---|---|
| `type` | ✔ | `mcq` `short` `fill` `tf` `match` `order` `table` `explain` `creative` `long`، أو `passage` (نص بلا درجة) |
| **حقول المادّة** | ✔ | كما في `fields` في المواصفات: الرياضيات `ao` (AO1–AO3) و`level` (L/M/H)؛ العلوم ١١–١٢ `ao` (AO1/AO2)؛ العربية `strand` و`level` و`qtype`؛ التربية الإسلامية `element` و`level` و`qtype` (`spec_summary.py` يعرضها) |
| `marks` | ✔ | عدد صحيح |
| `lesson` | ✔ | رمز الدرس (من `lessons`) |
| `page` | ✔ | صفحة كتاب الطالب («٢٤–٢٥») |
| `objective` | ✔ | الهدف التعليمي (برمزه من الدليل إن وُجد) |
| `stem` | ✔ | نصّ السؤال |
| `answer` / `steps` | ✔ أحدهما | الإجابة، وخطوات الحل (قائمة) |
| `guidance` | موصى به | الإرشادات: توزيع الدرجة وما يُقبل |
| `group` | — | «الأول»، «الثاني»… ← عنوان «السؤال الأول» وترقيم المفردات داخله (أ، ب…) |
| `label` | — | تسمية صريحة للمفردة («ب-١») بدل الترقيم الآلي |
| `lines` | — | عدد أسطر الإجابة |
| `fig`, `fig_width` | — | صورة (مسار نسبةً إلى ملف JSON) وعرضها بالنسبة المئوية |
| `parts` | — | أجزاء: `[{"label": "أ", "stem": "…", "lines": 1}]` |

حقول خاصة بالنوع:
- `mcq`: `"choices": [٤ بدائل]`، `"answer": رقم البديل الصحيح بدءاً من 0`، `"choice_cols": 4 أو 2`.
- `tf`: `"explain": true`، و`answer` «صواب/خطأ؛ لأن…».
- `match`: `"left"`، `"right"` (أكثر بواحد)، `"pairs"` (رقم بديل كل بند بدءاً من 0)، `left_title`، `right_title`.
- `order`: `"items"`. `table`: `"grid": {"rows": [["س", "١"], ["ص", ""]], "header": true}`.
- `passage`: `"title"`، `"body"` (نص، `\n` للفقرات)، `"verses": [["الصدر", "العجز"], …]` للأبيات، `"source"` (الشاعر أو المصدر).
  يوضع قبل أسئلته، ولا يُرقَّم ولا يدخل الشبكة.

## صيغة الرموز (الورقة ودليل التصحيح، PDF وWord) — تحقّق بعينك: `engine/notation_sheet.py`
| تكتب | يظهر |
|---|---|
| `{٣/٤}`، `{٢ ١/٣}` | كسر بخطٍّ أفقي، وعدد كسري (الصحيح يمين الكسر). البسط والمقام أي صيغة: `{س^{٢} + ١/٤}` |
| `٥^{٢}`، `س_{١}` | أسّ (في الرياضيات العربية **أعلى يسار** الأساس كالكتاب؛ وفي العلوم اللاتينية يمينه)، ودليل سفلي |
| `√{١٦}`، `√[٣]{١٢٥}` | جذر بعلامة **معكوسة** كالكتاب (في Word صورة دقيقة)، والدليل أعلى يمينها |
| `٠.‾{٣}` | عشري دوري (خطّ فوق الرقم) |
| `ce{2H2 + O2 -> 2H2O}` | معادلة كيميائية: أرقام سفلية، شحنات `^{2+}` أو `^+`، أسهم `->` `<=>`، حالات `(aq)` |
| `ltr{F = ma}` | عبارة لاتينية كاملة من اليسار لليمين (تُحلَّل داخلها الأسس والأدلة) |
| `quran[112:1-4]` | الآيات تُجلب من quran.com وتُدرج بين ﴿ ﴾ مع أرقامها واسم السورة؛ `quran[103\|imlaei]` بالرسم الإملائي |
| `quran[17:23]{فَلَا تَقُل لَّهُمَآ أُفٍّ}` | اقتباس من آية: يُتحقّق آلياً أنه جزء منها حرفاً حرفاً ثم يُعرض وحده |
| `u{يراجعُ}` | خطّ تحت الكلمة («أعرب ما تحته خط») |
| `**نص**`، `___`، `\n`، `\{` | غامق، فراغ للإجابة، سطر جديد، قوس حرفي |
- **أرقام المحتوى** حسب المواصفات (`digits`): `ar` (الرياضيات والعربية والتربية الإسلامية) تحوّل اللاتينية إلى (٠–٩) إلا داخل
  الرموز اللاتينية (7Ni2، AO1)؛ و`latin` (العلوم) تبقيها، ويعزل المحرّك كل كمية (20 mL، 5 × 10^{3}، 9.81 m/s^{2}) وكل معادلة
  طرفها الأيسر رمز لاتيني (n(Mg) = 4.8 g ÷ 24 g/mol) من اليسار لليمين آلياً. **ترقيم الأسئلة والدرجات عربي دائماً.**
- الفاصلة العشرية `٣.٤` أو `٣،٤` (بلا مسافة) ← «٣٫٤»؛ والقوائم `١، ٢، ٣` (مع مسافة). « - » ← «−»، « * » ← «×»، «%» ← «٪».
- **أخطاء تمنع البناء:** أسّ أو جذر بلا قوسين، قوس غير مغلق، أرقام عربية داخل `ce{}`، أخطاء التشكيل البنيوية (`arabic_check.py`)،
  وآية أو اقتباس لا يطابق المصدر. **تنبيهات:** كسر بشرطة مائلة في النص، x للضرب، «-» للسالب، أرقام عربية مع وحدات لاتينية،
  ترقيم لاتيني في نص عربي.

## الناتج
`<العنوان>_نموذج_أ.pdf/.docx`، `<العنوان>_نموذج_ب.pdf/.docx`، `<العنوان>_دليل_التصحيح.pdf/.docx` (وملفات HTML وسيطة، ومجلد
`<العنوان>_صور` لصور الجذور في Word). دليل التصحيح أفقي: لكل نموذج شبكة المفردات بحقول المادّة، وملخّص التوزيع مقابل المطلوب
(أخضر مطابق، أحمر مخالف)، ثم جدول التصحيح **بأعمدة وثيقة المادّة نفسها** (`answer_key` في المواصفات).

## الإعداد `exam-khotta.config.json` (في مجلد المعلّم أو أي مجلد أعلى من ملف الاختبار)
`teacher_name`، `school`، `directorate`، `year`، `reviewer_title`، `subject`، `grades`، `semester`؛ واختيارياً `country` و`ministry`
(رأس الورقة؛ الافتراضي «وزارة التعليم»)، و`docx_font` (Arial للرياضيات والعلوم، Traditional Arabic للعربية والتربية الإسلامية)، و`quran_font` (خط الآيات في Word).

### شكل الورقة `paper_style`
- **`table` (الافتراضي)**: الشكل المعتاد في مدارس السلطنة: يميناً الجهات (سلطنة عُمان، الوزارة، المديرية، المدرسة)، وفي الوسط
  الشعار، ويساراً خانة الدرجة (خانة فارغة فوق الدرجة الكلية). ثم العنوان مسطّراً في سطرين («الاختبار القصير الأول للصف السابع في
  مادة الرياضيات» / «للفصل الدراسي الأول للعام الدراسي ٢٠٢٦/٢٠٢٧م»)، وسطر النموذج والزمن، وخانتا «الاسم» و«الصف: ٧/ …»، ثم
  التعليمات، ثم جدول «المفردة | السؤال | الدرجة» (الدرجة بين قوسين [٢])، وعبارة الختام في إطار، وإطار مزدوج حول كل صفحة.
- `cards`: الشكل السابق (رأس من ثلاثة أعمدة، والمفردات بلا جدول).
- مفاتيح اختيارية لنمط `table`:
  | المفتاح | المعنى | الافتراضي |
  |---|---|---|
  | `logo` | مسار صورة الشعار (PNG أو JPG)، نسبةً إلى مجلد الإعداد | بلا شعار |
  | `choice_letters` | إظهار (أ) (ب) (ج) (د) قبل بدائل الاختيار من متعدد | `false`: البدائل في سطر بلا ترقيم، والسؤال بصيغة «حوّط …» (`WRITING.md`) |
  | `closing` | عبارة الختام (`""` لحذفها) | «انتهت الأسئلة مع تمنياتي للجميع بالنجاح والتفوّق» |
  | `show_teacher` | اسم المعلّم أسفل الورقة | `false` |
- يمكن تغيير الشكل لاختبار واحد بـ `"paper_style"` في ملف الاختبار، والتعليمات بـ `"instructions"` (الافتراضي «أجب عن جميع
  الأسئلة التالية»، وتُضاف ملاحظة الآلة الحاسبة بين قوسين).
- الشعار ملفّ المعلّم في مجلده؛ لا يُضاف إلى المهارة.
