# ملف الاختبار (JSON)

ملف واحد يُبنى منه كل شيء: `python3 <S>/engine/build_exam.py <الملف>.json [--out مجلد] [--log <P>/exams/log.json] [--check]`.
أمثلة كاملة: `examples/math7-1_short-test-1.json` (اختبار قصير) و`examples/math7-1_quiz-1.json` (سؤال قصير).

## الرأس
```json
{
 "kind": "short_test",            // أو "quiz"
 "spec": "math-5-10",             // ملف المواصفات في specs/
 "subject": "math", "grade": 7, "semester": 1,
 "title": "الاختبار القصير الأول",
 "grid": "مقترح ١",               // للتوثيق فقط
 "lessons": [{"code": "١-١", "title": "…", "pages": "١٦–٢١"}, …],
 "calculator": null,              // اختياري: يُستنتج من الوثيقة حسب الصف (ممنوعة ٥–٧)
 "instructions": "أجب عن جميع الأسئلة في الورقة نفسها",   // اختياري
 "header": {"school": "…"},       // اختياري: يغلب exam-khotta.config.json لهذا الاختبار
 "forms": {"أ": [مفردات…], "ب": [مفردات…]}
}
```

## المفردة
| الحقل | إلزامي | المعنى |
|---|---|---|
| `type` | ✔ | `mcq` `short` `fill` `tf` `match` `order` `table` `explain` `creative` `long` |
| `ao` | ✔ | `AO1` معرفة، `AO2` تطبيق، `AO3` استدلال |
| `level` | ✔ | `L` منخفض، `M` متوسط، `H` مرتفع |
| `marks` | ✔ | عدد صحيح |
| `lesson` | ✔ | رمز الدرس (من `lessons`) |
| `page` | ✔ | «ص ٢٤–٢٥» (كتاب الطالب) |
| `objective` | ✔ | الهدف التعليمي برمزه من الدليل |
| `stem` | ✔ | نصّ السؤال |
| `answer` / `steps` | ✔ أحدهما | الإجابة، وخطوات الحل (قائمة) |
| `guidance` | موصى به | الإرشادات: توزيع الدرجة وما يُقبل |
| `lines` | — | عدد أسطر الإجابة (افتراضي حسب النوع) |
| `fig`, `fig_width` | — | صورة (مسار نسبةً إلى ملف JSON) وعرضها بالنسبة المئوية (افتراضي ٤٥) |
| `parts` | — | أجزاء: `[{"label": "أ", "stem": "…", "lines": 1}]` (للإجابة الطويلة غالباً) |

حقول خاصة بالنوع:
- `mcq`: `"choices": [٤ بدائل]`، `"answer": رقم البديل الصحيح بدءاً من 0`، `"choice_cols": 4 أو 2` (اختياري).
- `tf`: `"explain": true` (إلزامي في الاختبار القصير)، و`answer` «صواب/خطأ؛ لأن…».
- `match`: `"left": [البنود]`، `"right": [البدائل، أكثر بواحد]`، `"pairs": [رقم بديل كل بند بدءاً من 0]`، `left_title`، `right_title`.
- `order`: `"items": [العناصر بترتيب مخلوط]`.
- `table`: `"grid": {"rows": [["س", "١", "٢"], ["ص", "", ""]], "header": true}` (الخلايا الفارغة للطالب).

## صيغة النصوص
| تكتب | يظهر |
|---|---|
| `{٣/٤}` | كسر بخطٍّ أفقي (معادلة حقيقية في Word) |
| `{١ ٢/٣}` | عدد كسري |
| `س^{٢}` | أُسّ |
| `√{١٦}` | جذر |
| `___` | فراغ للإجابة |
| `**نص**` | غامق |
| `\n` | سطر جديد |
- الأرقام اللاتينية تُحوَّل آلياً إلى عربية (٠–٩)، إلا داخل الرموز اللاتينية (7Ni2، AO1).
- الفاصلة العشرية: `٣.٤` أو `٣،٤` (بلا مسافة) ← «٣٫٤». القوائم: `١، ٢، ٣` (مع مسافة).
- « - » بين مسافتين ← «−»، و« * » ← «×». الأفضل كتابة «−» و«×» و«÷» مباشرة.

## الناتج
`<العنوان>_نموذج_أ.pdf/.docx`، `<العنوان>_نموذج_ب.pdf/.docx`، `<العنوان>_دليل_التصحيح.pdf/.docx`
(وملفات HTML وسيطة يمكن حذفها أو طباعتها). دليل التصحيح أفقي: لكل نموذج شبكة المفردات وملخّص التوزيع مقابل المطلوب
(أخضر مطابق، أحمر مخالف) ثم جدول التصحيح بأعمدة الوثيقة.

## الإعداد `exam-khotta.config.json` (في مجلد المعلّم أو أي مجلد أعلى من ملف الاختبار)
`teacher_name`، `school`، `directorate`، `year`، `reviewer_title`، `subject`، `grades`، `semester`؛ واختيارياً
`country` و`ministry` (رأس الورقة)، و`docx_font` (افتراضي Arial)، و`digits` (`ar` افتراضي، أو `latin`).
